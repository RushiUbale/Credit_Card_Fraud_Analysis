# 💳 Credit Card Transaction Fraud Analysis

## 📌 Project Overview
An end-to-end data analytics project analyzing 500,000 credit card transactions to identify fraud patterns and generate business insights using Python, MySQL, SQL, and Power BI.

## 🛠️ Technologies Used
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- MySQL
- SQL
- Power BI

## 📊 Key Analysis
- Fraud vs Non-Fraud Transactions
- Customer Spending Analysis
- Merchant Category Analysis
- Monthly and Hourly Fraud Trends
- Geographical Fraud Analysis
- Customer Risk Classification

## 📈 Key Results
- Total Transactions: 500,000
- Fraudulent Transactions: 2,894
- Fraud Rate: 0.58%
- Fraud Amount: ₹15.82 Lakh
